# 🍅 Tomato Pasta with Vegetables Website

A clean, professional, beginner-friendly **multi-page recipe website** built using **pure HTML, CSS, and JavaScript** — no frameworks, no libraries.

🔗 **Live Demo:**  
https://soumikavumi.github.io/tomato-pasta-website/

---

## 📌 Project Overview

This project is a simple recipe website for **Tomato Pasta with Vegetables**.  
It was created to practice core web development skills such as:

- Structuring multi-page websites
- Writing clean, reusable CSS
- Using JavaScript for interactivity
- Working with `localStorage`
- Deploying projects using **GitHub Pages**

The design is intentionally **clean, modern, and professional**, with a dark gradient background and readable typography.

---

## ✨ Features

- 📄 **Multiple pages**
  - Home
  - Ingredients
  - Cooking Steps
  - Why the Recipe is Healthy
  - Vitamins Information
  - Comments

- 🎨 **Single shared CSS file**
  - Consistent styling across all pages
  - Dark modern gradient background

- ⚙️ **Single shared JavaScript file**
  - Active navigation highlighting
  - Show/Hide buttons
  - LocalStorage-based comments system
  - Safe DOM checks

- 💬 **Comments system**
  - Users can add comments
  - Comments persist using `localStorage`

- 🖼️ **Recipe image**
  - Image generated using ChatGPT
  - Proper attribution included
